# Personal Website

A modern personal portfolio website built with [Next.js](https://nextjs.org), TypeScript, and Tailwind CSS.

## Features

- 🌑 Dark mode design
- 📱 Fully responsive
- ⚡ Fast & accessible
- 🎨 Clean, modern UI with smooth transitions
- 📋 Easy to customize via `src/data/profile.ts`

## Sections

- **Hero** — Introduction and call to action
- **About** — Bio and personal highlights
- **Skills** — Tech stack organized by category
- **Projects** — Portfolio of projects with links
- **Contact** — Email and social links

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the site.

## Customization

Edit `src/data/profile.ts` to update your name, bio, skills, projects, and social links.

## Deploy

Deploy instantly on [Vercel](https://vercel.com/new).
